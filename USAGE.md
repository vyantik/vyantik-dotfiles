## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/vyantik/vyantik-dotfiles.git ~/dotfiles
cd ~/dotfiles
```

### 2. Запуск установщика
```bash
./main.sh
```

## 🛠️ Отдельное использование скриптов

Каждый компонент можно установить отдельно:

```bash
# Установка только Hyprland
./scripts/install_hypr.sh

# Установка только шрифтов
./scripts/install_fonts.sh

# Установка только Fish shell
./scripts/install_fish.sh
```

## 🔧 Настройка после установки

### Hyprland
1. Выберите Hyprland в менеджере дисплея
2. Настройте мониторы в `~/.config/hypr/monitors.conf`:
```bash
monitor=DP-1,2560x1440@144,0x0,1
monitor=HDMI-A-1,1920x1080@60,2560x0,1
```

### Fish Shell
1. Перезапустите терминал
2. Fish автоматически станет оболочкой по умолчанию
3. Проверьте переменные окружения:
```bash
echo $PATH
echo $GOPATH
echo $BUN_INSTALL
```

### Neovim
1. Запустите `nvim`
2. Плагины установятся автоматически при первом запуске
3. Дождитесь завершения установки Lazy.nvim

### Цветовые схемы
Используйте pywal для автоматической генерации:
```bash
wal -i ~/Pictures/wallpaper.jpg
```

## 📝 Логи и диагностика

### Просмотр логов
```bash
# Логи всех компонентов
ls /tmp/install_*.log

# Просмотр конкретного лога
cat /tmp/install_hypr.log
```

### Проверка установленных пакетов
```bash
# Проверка пакетов Hyprland
pacman -Q | grep hypr

# Проверка шрифтов
fc-list | grep -i jetbrains
```

## 🔄 Повторная установка

Если компонент не установился:
1. Проверьте логи в `/tmp/install_*.log`
2. Исправьте проблемы (права, интернет, зависимости)
3. Запустите установщик снова
4. Выберите только проблемный компонент

## 🆘 Решение проблем

### Права доступа
```bash
# Если нет прав sudo
su -
usermod -aG wheel username
```

### AUR пакеты
```bash
# Установка yay вручную
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
```

### Конфликты пакетов
```bash
# Поиск конфликтующих пакетов
pacman -Qo /usr/bin/conflicting-binary
# Удаление конфликтующего пакета
sudo pacman -R conflicting-package
```

### Проблемы с сетью
```bash
# Проверка DNS
nslookup google.com
# Обновление зеркал
sudo pacman -Syy
```

## 🎨 Кастомизация

### Waybar
Отредактируйте `~/.config/waybar/config.jsonc` для изменения модулей

### Rofi
Измените тему в `~/.config/rofi/config.rasi`

### Hyprland
Настройте горячие клавиши в `~/.config/hypr/hyprland.conf`
