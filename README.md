# Dotfiles Installer

Автоматический установщик конфигураций для Arch Linux с интерактивным CLI интерфейсом.

## 📸 Результат установки

![Рабочий стол с установленными dotfiles](pictures/example.png)

*Полностью настроенная система с Hyprland, Waybar, Rofi и другими компонентами*

## 🚀 Особенности

- **Интерактивный CLI** с цветным выводом и меню
- **Модульная установка** - выбирайте только нужные компоненты
- **Автоматическая установка зависимостей** для каждого компонента
- **Резервное копирование** существующих конфигураций
- **Подробный отчет** об успешности установки в виде таблицы
- **Логирование** всех операций для диагностики

## 📦 Компоненты

### 🛠️ Базовые утилиты
- **fd** - быстрый поиск файлов (замена find)
- **ripgrep** - молниеносный поиск по тексту (замена grep)
- **fzf** - интерактивный фильтр для командной строки
- **bat** - улучшенный cat с подсветкой синтаксиса
- **exa** - современная замена ls с Git интеграцией
- **zoxide** - умная навигация по директориям
- **htop, git, curl, wget** и другие essential инструменты

### 🎨 Hyprland WM
- **Hyprland** - современный Wayland композитор
- **Waybar** - настраиваемая панель
- **Rofi** - лаунчер приложений
- **SwayNC** - центр уведомлений
- **Wlogout** - меню выхода
- **Поддержка скриншотов** и буфера обмена

### 🐚 Fish Shell
- **Fish** - дружелюбная командная оболочка
- **Fastfetch** - быстрый системный информер
- **Интеграция с Bun, Go, Rust, Spicetify**
- **Автоматическая настройка PATH**

### 🖥️ Kitty Terminal
- **GPU-ускоренный терминал**
- **Поддержка pywal** для цветовых схем
- **Прозрачность и кастомизация**
- **Ligatures поддержка**

### ✏️ Neovim Editor
- **Конфигурация на базе AstroNvim**
- **LSP серверы** для разных языков программирования
- **Автоматическая установка плагинов**
- **Tree-sitter подсветка синтаксиса**

![Neovim с установленными плагинами](pictures/nvim_example.png)

*Neovim с современным интерфейсом, LSP и плагинами для разработки*

### 📁 Thunar File Manager
- **Легкий файловый менеджер**
- **Поддержка архивов** и медиа-тегов
- **GVFS интеграция** для сетевых дисков
- **Кастомные действия**

### 🗂️ Yazi File Manager
- **Современный файловый менеджер для терминала**

### 🐳 Docker & Docker Compose
- **Платформа контейнеризации** для изолированных приложений
- **Docker Compose** для управления многоконтейнерными приложениями
- **Автоматическая настройка** сервиса и пользовательских групп
- **Готовые примеры** конфигураций в ~/docker-examples

### 🔤 Шрифты и иконы
- **Nerd Fonts** (JetBrains Mono, Fira Code, Hack)
- **Font Awesome** для иконок интерфейса
- **Papirus icon theme**
- **Emoji поддержка**

### 🛠️ CLI утилиты
- **chpaper** - утилита для смены обоев рабочего стола
- **json-parse** - быстрый парсер JSON файлов

## 🛠️ Установка

### Системные требования
- Arch Linux или производная
- Права sudo
- Подключение к интернету
- Git (устанавливается автоматически)

### Быстрый старт

```bash
# Клонирование репозитория
git clone <your-repo-url> ~/dotfiles
cd ~/dotfiles

# Запуск установщика
./main.sh
```

### Использование

1. **Установить все компоненты** - полная автоматическая установка
2. **Выборочная установка** - выберите только нужные компоненты
3. **Показать статус** - посмотреть что уже установлено
4. **Справка** - подробная информация о каждом компоненте

## 🔧 Кастомизация

### Мониторы
Отредактируйте `~/.config/hypr/monitors.conf` для настройки ваших мониторов:
```bash
monitor=DP-1,2560x1440@144,0x0,1
monitor=HDMI-A-1,1920x1080@60,2560x0,1
```

### Цветовые схемы
Используйте `pywal` для автоматической генерации цветовых схем:
```bash
wal -i ~/Pictures/wallpaper.jpg
```

### Waybar модули
Кастомизируйте панель в `~/.config/waybar/config.jsonc`

### Yazi конфигурация
Настройте файловый менеджер в `~/.config/yazi/yazi.toml`:
```toml
[manager]
show_hidden = true
sort_by = "modified"
sort_reverse = true
```

### Docker использование
После установки Docker доступны готовые примеры:
```bash
cd ~/docker-examples
docker-compose up -d    # запуск nginx + redis
docker-compose down     # остановка сервисов
```

## 🐛 Диагностика

### Логи установки
Логи сохраняются в `/tmp/install_*.log` для каждого компонента.

### Проверка статуса
```bash
./main.sh
# Выберите опцию 3 для просмотра статуса
```


### Частые проблемы

1. **Ошибки прав доступа**: Убедитесь, что у вас есть sudo права
2. **Сетевые ошибки**: Проверьте подключение к интернету
3. **AUR пакеты**: Установите `yay` или `paru` для доступа к AUR
4. **Конфликты пакетов**: Удалите конфликтующие пакеты вручную
